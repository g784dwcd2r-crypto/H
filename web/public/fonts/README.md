# Disclosure fonts

These WOFF2 files are derived from the user-supplied `Albert_Sans,EB_Garamond.zip` archive (September 2026). Font names, full character coverage and the supplied Regular/Medium designs are retained. The duplicate `EB_Garamond.zip` is not needed at runtime.
